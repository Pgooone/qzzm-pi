# 校园二手书交易平台 — PRD

**版本:** v1  
**作者:** 需求 Agent  
**日期:** 2026-05-08

---

## 1. 项目背景与目标

### 背景
- 高校每学期教材更新频率低，大量旧书被闲置或当作废纸出售，浪费严重。
- 学生购书渠道单一（校内书店/网购），价格偏高；卖书缺乏便捷的校内流转平台。
- 现有二手交易平台（闲鱼等）非校园封闭场景，缺乏同学信任与便捷的线下交接机制。

### 目标
- 搭建一个**仅限本校学生使用**的轻量级二手书交易平台，实现图书的快速发布、搜索与一对一交易，降低学生购书成本，提高书籍循环利用率。

---

## 2. 核心用户与场景

### 用户角色
| 角色 | 描述 |
|------|------|
| 买家 | 需要购买指定教材或课外书的本校学生 |
| 卖家 | 有闲置书籍希望出售的本校学生 |
| 平台管理员 | 维护平台正常运营，审核违规信息 |

### 用户故事

1. **作为** 一名在校学生（卖家），**我想** 拍照并填写书名、价格、联系方式后快速上架我的闲置教材，**以便** 有人购买并线下交接。

2. **作为** 一名在校学生（买家），**我想** 按课程名称或教材名称搜索二手书，**以便** 快速找到我需要的那本书并以更低价格买到。

3. **作为** 一名在校学生（买家/卖家），**我想** 通过平台内置聊天或留言功能沟通交易细节，**以便** 约定面交时间地点，完成交易。

## 3. 功能列表

### P0（必须）
| 序号 | 功能 | 说明 |
|------|------|------|
| 1 | 用户注册与校内认证 | 使用学校邮箱或学生证号注册，验证通过后可使用平台 |
| 2 | 图书发布（上架） | 卖家上传照片、书名、作者、价格、新旧程度、联系方式等信息 |
| 3 | 图书搜索与浏览 | 按书名/课程名/关键词搜索，支持按价格、新旧程度排序 |

### P1（重要）
| 序号 | 功能 | 说明 |
|------|------|------|
| 4 | 图书详情页与联系卖家 | 展示完整图书信息，买家可通过站内消息或电话联系卖家 |
| 5 | 订单管理（标记已售） | 卖家标记图书为"已售出"，下架商品 |

### P2（锦上添花）
| 序号 | 功能 | 说明 |
|------|------|------|
| 6 | 图书收藏/关注 | 买家可收藏感兴趣的书，上架时即时通知 |
| 7 | 交易评价与信誉分 | 交易完成后买卖双方互评，累积信誉分 |

## 4. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 页面加载 ≤ 2 秒；搜索响应 ≤ 1 秒；支持同时 500 人在线 |
| 安全 | 用户身份通过学校邮箱/学号验证；联系方式仅对交易双方可见 |
| 兼容性 | 适配移动端 H5 与微信小程序，支持 iOS / Android 主流浏览器 |
| 可用性 | 7×24 小时运行，月可用率 ≥ 99.5% |

## 5. 验收标准

### P0-1 用户注册与校内认证
1. 用户使用 **@xxx.edu.cn** 邮箱注册后可收到验证邮件，点击后完成注册。
2. 使用学生证号手工审核时，管理员后台可搜索到对应学生信息。
3. 未认证用户无法发布图书，仅可浏览。

### P0-2 图书发布（上架）
1. 卖家上传至少 1 张图书照片后可提交表单。
2. 必填字段（书名、价格、联系方式）为空时提交被拦截并提示。
3. 发布成功后，图书立即在搜索结果中可见。

### P0-3 图书搜索与浏览
1. 搜索"高等数学"可返回书名或课程名中包含"高等数学"的所有在售图书。
2. 按价格升序排列时，结果正确排序。
3. 无搜索结果时显示友好空状态提示。

## 6. 里程碑与风险

### 里程碑
| 阶段 | 时间 | 交付物 |
|------|------|--------|
| MVP 开发 | 第 1-3 周 | 完成 P0 功能，包含 H5 页面与后端 API |
| 校内内测 | 第 4 周 | 选取 1-2 个班级进行小范围测试，收集反馈 |
| 正式上线 | 第 5 周 | 全校范围推广，开放注册 |

### 主要风险
| 风险 | 影响 | 应对策略 |
|------|------|----------|
| 学生认证流程复杂导致注册转化低 | 高 | 支持邮箱自动验证 + 学号审核双通道 |
| 交易纠纷（如书况不符、爽约） | 中 | 发布时强制填写新旧程度 + 后期引入评价体系 |
| 平台冷启动，无初始书籍 | 高 | 上线前邀请 10 名种子用户预发布图书 |
